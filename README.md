## 📖 О проекте

**Echoes On Tape** — это официальный сайт независимого музыкального лейбла, вдохновлённого эстетикой 80-х, неоном и синтезаторами. Сайт построен на **чистом HTML, CSS и JavaScript** без использования фреймворков, что обеспечивает максимальную производительность и полную кастомизацию.

### ✨ Ключевые особенности

- 🎨 **Synthwave UI** — неоновые градиенты, glow-эффекты, шрифт Orbitron
- 🎬 **Плавные анимации** — FLIP-анимации, параллакс-эффекты, дыхание логотипа
- ✨ **Particles.js** — интерактивные частицы в hero-секции
- 🎯 **Умная фильтрация** — релизы фильтруются по артисту с плавной анимацией (Spotify/Pinterest-style)
- 🎵 **Yandex Music плееры** — встроенные треки с автоплеем
- 📱 **Полная адаптивность** — идеально работает на ПК, планшетах и мобильных устройствах
- ⚡ **Высокая производительность** — оптимизированный код без лишних зависимостей

## 🎨 Особенности реализации

### FLIP-анимации
Используется техника FLIP (First, Last, Invert, Play) для плавной анимации карточек релизов при фильтрации.

### Параллакс-эффекты
- Параллакс для hero-секции
- Динамическое движение логотипа в секции релизов

### Адаптивный дизайн
- Mobile-first подход
- Breakpoints для разных размеров экранов
- Оптимизированные изображения
