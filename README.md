# Echoes On Tape 
*Неоновый музыкальный лейбл в стиле synthwave / cyberpunk*

[Посетить сайт →](https://https://akaikage15.github.io/Echoes-On-Tape-web-site/)

---

## О проекте

**Echoes On Tape** — это официальный сайт независимого музыкального лейбла, вдохновлённого эстетикой 80-х, неоном и синтезаторами.  
Сайт построен на **чистом HTML, CSS и JavaScript** — без фреймворков, с максимальной производительностью и кастомизацией.

---

## Особенности

| Фича | Описание |
|------|--------|
| **Synthwave UI** | Неоновые градиенты, glow-эффекты, Orbitron шрифт |
| **Параллакс & Анимации** | Плавные скролл-эффекты, дыхание логотипа |
| **Particles.js** | Интерактивные частицы в hero-секции |
| **Плавная фильтрация** | Релизы фильтруются по артисту с анимацией |
| **Yandex Music плееры** | Встроенные треки с автоплеем |
| **Адаптивность** | Идеально на ПК, планшетах и мобильных |
| **Live Server Ready** | Работает локально и на GitHub Pages |

---


## Технологии

- **HTML5**
- **CSS3** (Flexbox, Grid, Animations, Transitions)
- **Vanilla JavaScript**
- **Particles.js** — интерактивные частицы
- **Google Fonts** — Orbitron
- **Yandex Music iframe API**
